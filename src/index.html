Local AI Assistant Bridge & Automation
Any AI assistant (Antigravity, Claude, Cursor, Copilot, ChatGPT) can control CopyCat media player live over HTTP and launch playback directly onto your interactive desktop.
Endpoint: http://127.0.0.1:4500 Status: GET http://127.0.0.1:4500/api/status Control: POST http://127.0.0.1:4500/api/control CLI: copycat [filePath]
🚀 How AIs Launch Without Background Sandbox Termination:
# From any AI terminal on Windows, use explorer or the copycat CLI: copycat "C:\path\to\video.mp4" # Or via Windows Explorer (bypasses service desktop sandbox): Start-Process explorer.exe "$env:LOCALAPPDATA\Programs\copycat-media-player\CopyCat media player.exe"
PowerShell Live Control Example:
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:4500/api/control -ContentType 'application/json' -Body '{"action":"openFile","filePath":"C:\\Videos\\sample.mp4"}'
